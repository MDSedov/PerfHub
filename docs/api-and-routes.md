# HTTP-маршруты PerfHub: AS-IS

Срез 12.10.2026. **A — декларации и реализация контроллеров**, не проверка HTTP работающего приложения. Инвентаризированы все 87 обработчиков аннотаций в 20 контроллерах; ссылки ниже ведут на исходники. Сохранены завершающие `/`: эквивалентность URL без них не предполагается. Названия DTO задают точный формат; ключевые поля приведены ниже. `!` означает обязательность по DTO/сервису, `?` — необязательность. Для остальных нюансов сериализации источник — соответствующий record.

## Общие правила доступа и ошибок

- **USER/ADMIN**: активная сессия обязательна. Гость API получает 401 с `message`; гость HTML — 302 на `/login?redirect=...`. **ADMIN**: дополнительно проверяется роль, иначе 403. Эти правила применяются к каждой строке таблицы независимо от её предметной ошибки.
- **H**: обычный HTML-маршрут DashboardController; входных данных кроме сессии нет. Ошибка рендера или хранилища может перейти в стандартную обработку Spring.
- **L**: DropAppExceptionHandler для DropAppController/LoadTestController: DropAppClientException → 502, IllegalArgumentException/IllegalStateException → 400, ResponseStatusException сохраняет статус; тело `message`.
- **V**: VictoriaMetricsExceptionHandler: неизвестный запрос/период/валидация → 400, клиент/обработка ответа → 502; `message`.
- **G**: GrafanaExceptionHandler: период/валидация/GrafanaRenderingException → 400, GrafanaClientException → 502; `message`.
- **R**: RequirementExceptionHandler: RequirementEvaluationException/VmQueryNotFoundException → 400, VM client/processing → 502; `message`. Bean validation здесь не унифицирована собственным advice.
- **C**: ConfluenceExceptionHandler: операция/валидация/Grafana range/render → 400, GrafanaRenderNotCachedException → 409, Grafana/Confluence client → 502; `message`.
- **A** в колонке ошибок (код обработчика, не категория знания): GigachatExceptionHandler: prompt not found/нет VM/валидация → 400; загрузка prompt → 500; клиент → 502.
- **T**: ConfluenceTemplateSettingsExceptionHandler: IllegalArgumentException/валидация → 400 с `message`.
- **U**: UserControllerExceptionHandler для UserAdmin/TestTypeAdmin/Profile: IllegalArgumentException → 400 с `message`.
- **D**: отдельного предметного advice для контроллера нет. Ошибки binding/JSON/валидации обрабатывает Spring; ошибки сервиса/SQL не следует автоматически считать 400. Форма и сообщения HTTP не проверены MVC-тестом.

Для всех API, кроме явно указанных ZIP/void, ответ JSON; успех по коду 200, включая создание. Отдельное удаление снимка возвращает 204. Неверные типы path/JSON обрабатываются MVC до вызова сервиса. Необработанные исключения возможны и в группах с advice; перечисление не обещает единого ответа на любой сбой.

## Составные входные и выходные данные

- `UserSave`: username, firstName, lastName, role, password, passwordConfirmation; `ProfileSave` — те же персональные поля без role. Username/firstName обязательны, lastName может быть пустой. `UserDto` не содержит password/hash.
- `TemplateSave`: shortName, fullName, reportTitle!, reportTitleShort, templateType!, testType, templatePageId, text, charts:[{title!,dashboardUid!,panelId>0}]. Системное shortName выводится из типа; не все принятые поля являются независимыми настройками.
- `DashboardUpdate`: slug!, title?, panels!:[], enabled?, panelSettings:[{panelId!,selected!,title?,query?,threshold?,testQuery?}], variables:[{name!,label,type,value,defaultValue,options}]. Сервис использует query/threshold из кеша Grafana, а не произвольные значения входного panelSettings.
- `LegacyRequirement`: code!,metricType!,thresholdValue!,thresholdUnit!,descriptionRu,active!,parameters (JSON). Это контракт существующего контроллера, не подтверждение работоспособности его SQL.
- `ReportLink`: testUuid!, testNumber?, testTitle?, testTitleShort?, reportPageId!, reportPageTitle?, reportPageUrl?.
- `C-headers`: необязательные X-Confluence-Login / X-Confluence-Token объявлены контроллером; фактический token берётся из конфигурации. Не считать token header поддержанным override (Q-07).
- `LoadTestView`: идентификатор/период/тип и отображаемое название, комментарий, статус/выводы отчёта, сведения об оценке, релизе, Jira и конфигурации; см. record [LoadTestView](../src/main/java/perfhub/dto/tests/LoadTestView.java).
- `GrafanaRenderResponse`: from,to,dashboards; dashboard содержит UID/slug и панели (panel ID, title, description, image base64). Точная вложенность — [DTO Grafana](../src/main/java/perfhub/dto/grafana/GrafanaRenderResponse.java).
- `SnapshotDetails`: id,savedAt,release,jiraReleaseIssueKey,jiraReleaseIssueUrl,comment,namespaces,components,items,jiraReleaseDistributions,documents; строки ресурсов содержат namespace/service/pod/container, версии и CPU/RAM. [DTO снимка](../src/main/java/perfhub/dto/dropapp/DropAppConfigurationSnapshotDetailsDto.java).
- `ConfigurationItemDto`: описание параметра и его значение; чувствительные поля нельзя включать в примеры ответов или диагностические документы.

## Маршруты инфраструктуры и расхождения

`/error` обслуживается Spring Boot, `/css/**`, `/js/**`, `/img/**`, `/favicon.png` — статические ресурсы; interceptor также исключает `/webjars/**`. Это не дополнительные пользовательские контроллеры. Шаблон `index.html` не имеет явного handler; `/` перенаправляет на `/main`.

`settings-victoria-metrics.html` обращается к `/api/settings/victoria-metrics-queries`, но такого контроллера/handler нет (G-14). Он намеренно не включён как реализованный API. `/api/settings/non-functional-requirements` имеет контроллер и репозиторий, но отсутствующую в свежей схеме таблицу (G-03). Legacy hierarchy API и GigaChat token API описаны для полноты, не закреплены кандидатными требованиями (Q-01/Q-06).

Права, ошибки и сценарии требуют отдельных MVC-тестов. При рефакторинге нельзя вывести новый HTTP-контракт только из общей рекомендации стандартизировать ошибки. Трассировка требований baseline — [матрица](requirements/traceability.md).
