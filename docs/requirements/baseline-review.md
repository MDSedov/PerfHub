`openspec archive baseline-existing-perfhub --yes` выполнен успешно 12.10.2026: создан архив [2026-10-12-baseline-existing-perfhub](../../openspec/changes/archive/2026-10-12-baseline-existing-perfhub/proposal.md), штатно перенесены 41 ADDED requirement в восемь основных specs. Синхронизация не пропускалась. `refactor-shared-ui-layout` остался активным и неизменным. CLI выдал необязательную рекомендацию делить changes более чем с 10 deltas; для согласованного документирующего baseline сохранён утверждённый объём. Это не ошибка строгой валидации.

После переноса проверены формат main specs (Purpose/Requirements, без delta-заголовков), точное сохранение всех утверждённых нормативных блоков, 8/41/93 и ссылки. `openspec validate --specs --strict --json`: 8 успешных спецификаций, ошибок нет. Новые safety changes не считаются утверждёнными вместе с baseline.
