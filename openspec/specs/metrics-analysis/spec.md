# metrics-analysis Specification

## Purpose
Предоставить измерения для заданного периода и дополнительные результаты текстового анализа по настроенным промптам и доступным данным.

Статус: baseline официально согласован владельцем 12.10.2026. Зафиксирован существующий AS-IS; уровни доказательств сохранены. Спорные вопросы остаются в реестре, без изменения функций, статусов, временных интервалов и источников порогов НФТ.

## Requirements

### Requirement: PH-MET-001 Пакетное получение измерений

Система SHALL возвращать измерения для непустого набора известных типов запросов с единым допустимым периодом и сохранять последний агрегат для последующего анализа.

#### Scenario: PH-MET-001-S01 Несколько запросов

- **GIVEN** настроены запросы и доступны ответы VM
- **WHEN** передан непустой набор типов с одинаковыми start/end
- **THEN** ответ содержит общий период и результат каждого типа; агрегат доступен следующему анализу.

#### Scenario: PH-MET-001-S02 Неизвестный запрос или неверные границы

- **GIVEN** набор пуст, тип не найден, периоды различаются либо end не позже start
- **WHEN** запрошены измерения
- **THEN** операция отклоняется с сообщением об ошибке входа или настройки.

Доказательства и ограничения: [PH-MET-001](../../../docs/requirements/traceability.md#ph-met-001).

### Requirement: PH-MET-002 Анализ по сохранённому промпту

Система SHALL отправлять анализ по существующему ключу промпта с подстановкой переданных переменных и возвращать ответ сервиса анализа.

#### Scenario: PH-MET-002-S01 Промпт найден

- **GIVEN** настроен GigaChat и существует промпт с переменной
- **WHEN** переданы promptKey и значение переменной
- **THEN** переменная подставляется в текст, вызывается анализ, ответ возвращается вызывающему пользователю.

#### Scenario: PH-MET-002-S02 Промпт отсутствует

- **GIVEN** указан неизвестный ключ
- **WHEN** запрошен анализ
- **THEN** возвращается ошибка отсутствующего промпта без запроса completion по этому промпту.

Доказательства и ограничения: [PH-MET-002](../../../docs/requirements/traceability.md#ph-met-002).

### Requirement: PH-MET-003 Анализ последних измерений

Система SHALL позволять запросить анализ тестов или анализ соответствия по последнему доступному агрегату измерений и соответствующему настроенному промпту.

#### Scenario: PH-MET-003-S01 Есть измерения

- **GIVEN** получены измерения VM, настроены промпты и GigaChat
- **WHEN** запрошен анализ тестов либо соответствия
- **THEN** внешнему сервису передаются промпт и агрегат измерений; результат анализа возвращается пользователю API.

#### Scenario: PH-MET-003-S02 Измерения отсутствуют

- **GIVEN** подключение GigaChat корректно, но агрегат VM ещё не получен
- **WHEN** запрошен анализ
- **THEN** возвращается ошибка отсутствия данных VM; результат анализа не выдумывается.

Доказательства и ограничения: [PH-MET-003](../../../docs/requirements/traceability.md#ph-met-003).
