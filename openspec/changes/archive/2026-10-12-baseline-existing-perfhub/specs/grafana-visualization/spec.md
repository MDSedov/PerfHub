# Графики Grafana

## Purpose

Предоставить каталог графиков и их изображения для теста либо выбранного периода с учётом шаблона отчёта и настроенных переменных.

Статус: baseline официально согласован владельцем 12.10.2026. Зафиксирован существующий AS-IS; уровни доказательств сохранены. Спорные вопросы остаются в реестре, без изменения функций, статусов, временных интервалов и источников порогов НФТ.

## ADDED Requirements

### Requirement: PH-GRAF-001 Каталог графиков

Система SHALL предоставлять сохранённый каталог dashboard и панелей и позволять обновлять его из настроенной Grafana.

#### Scenario: PH-GRAF-001-S01 Сохранённый каталог

- **GIVEN** каталог ранее сохранён, Grafana сейчас недоступна
- **WHEN** пользователь открывает список графиков в настройках
- **THEN** возвращается локально сохранённый каталог без обязательного запроса обнаружения.

#### Scenario: PH-GRAF-001-S02 Обновление каталога

- **GIVEN** Grafana возвращает dashboard с панелями, в том числе внутри rows
- **WHEN** пользователь запрашивает обновление
- **THEN** каталог содержит найденные панели и их доступные query/threshold; существующий выбор панелей отражается в ответе.

Доказательства и ограничения: [PH-GRAF-001](../../../../../../docs/requirements/traceability.md#ph-graf-001).

### Requirement: PH-GRAF-002 Выбор графиков и переменных

Система SHALL сохранять настройки выбора панелей и значений переменных dashboard и использовать разрешённые значения переменных при получении изображений.

#### Scenario: PH-GRAF-002-S01 Сохранённая переменная

- **GIVEN** dashboard содержит переменную с выбранным непустым значением
- **WHEN** получается изображение его панели
- **THEN** в запросе рендера передано выбранное значение переменной.

#### Scenario: PH-GRAF-002-S02 Значение не определено

- **GIVEN** значение переменной dashboard не удалось определить
- **WHEN** получается изображение
- **THEN** не передаётся переменная с неразрешённым значением.

Доказательства и ограничения: [PH-GRAF-002](../../../../../../docs/requirements/traceability.md#ph-graf-002).

### Requirement: PH-GRAF-003 Графики выбранного теста

Система SHALL возвращать изображения графиков из шаблона типа выбранного теста за период этого теста с идентификаторами и названиями панелей.

#### Scenario: PH-GRAF-003-S01 Графики получены

- **GIVEN** тест существует, его типу соответствует шаблон с графиками, Grafana возвращает PNG
- **WHEN** запрошены графики теста
- **THEN** возвращаются период, dashboard и панели с изображениями в base64 и названиями.

#### Scenario: PH-GRAF-003-S02 Нельзя определить графики

- **GIVEN** тест отсутствует, период недопустим либо шаблон отсутствует или не содержит графиков
- **WHEN** запрошены графики
- **THEN** возвращается ошибка с причиной; успешный набор графиков не имитируется.

#### Scenario: PH-GRAF-003-S03 Ответ не изображение

- **GIVEN** Grafana вернула успешный HTTP-ответ с содержимым без PNG-сигнатуры
- **WHEN** обрабатывается результат рендера
- **THEN** ответ не выдаётся как корректное PNG-изображение.

Доказательства и ограничения: [PH-GRAF-003](../../../../../../docs/requirements/traceability.md#ph-graf-003).

### Requirement: PH-GRAF-004 Повторное использование изображений

Система SHALL переиспользовать подходящие сохранённые изображения теста, позволять принудительное обновление и предоставлять режим получения только уже сохранённых изображений.

#### Scenario: PH-GRAF-004-S01 Изображение сохранено

- **GIVEN** кеш соответствует тесту, шаблону, панели, периоду, переменным и параметрам изображения
- **WHEN** запрошены графики без forceRefresh
- **THEN** сохранённое изображение возвращается без повторного рендера этой панели.

#### Scenario: PH-GRAF-004-S02 Принудительное обновление

- **GIVEN** кеш существует, cacheOnly не включён
- **WHEN** запрошены графики с forceRefresh
- **THEN** изображение получается заново и сохраняется для последующего использования.

#### Scenario: PH-GRAF-004-S03 Только кеш

- **GIVEN** некоторые изображения не сохранены, forceRefresh не включён
- **WHEN** запрошен режим cacheOnly
- **THEN** возвращаются только найденные в кеше изображения; отсутствующие панели не рендерятся.

Доказательства и ограничения: [PH-GRAF-004](../../../../../../docs/requirements/traceability.md#ph-graf-004).

### Requirement: PH-GRAF-005 Графики произвольного периода

Система SHALL предоставлять графики выбранного шаблона либо одну входящую в него панель за явно заданный допустимый период.

#### Scenario: PH-GRAF-005-S01 Период задан явно

- **GIVEN** существует шаблон с графиками
- **WHEN** переданы templateId и from/to, в том числе Unix-время в секундах либо миллисекундах
- **THEN** изображения соответствуют выбранному шаблону и периоду.

#### Scenario: PH-GRAF-005-S02 Панель не принадлежит шаблону

- **GIVEN** существует шаблон
- **WHEN** для одиночного рендера передан dashboardUid/panelId вне его графиков
- **THEN** операция отклоняется с сообщением об ошибке.

Доказательства и ограничения: [PH-GRAF-005](../../../../../../docs/requirements/traceability.md#ph-graf-005).
