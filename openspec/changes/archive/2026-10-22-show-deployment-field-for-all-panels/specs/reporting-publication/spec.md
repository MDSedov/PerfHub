# Spec Delta

Статус: согласовано владельцем 22.10.2026 и реализовано; результаты восьми сценариев — в [Verify](../../verification.md). PH-REP-010 перенесён штатным Archive в основные specs 22.10.2026; действующие PH-REP-008/009 и PH-CFG-005 сохранены.

## ADDED Requirements

### Requirement: PH-REP-010 Постоянное поле Deployment в редакторе графиков

Система SHALL всегда показывать колонку Deployment и поле в каждой строке графика шаблона. Для подходящей панели с доступными вариантами поле SHALL разрешать выбор одного конкретного deployment. Для неприменимого выбора либо недоступных вариантов поле SHALL оставаться видимым и заблокированным с объяснением; неизвестная применимость SHALL отличаться от подтверждённой неприменимости. Перерисовка SHALL не менять сохранённые значения.

#### Scenario: PH-REP-010-S01 Новая строка и пустой шаблон

- **GIVEN** открыт шаблон любого поддержанного типа
- **WHEN** графиков нет либо пользователь добавляет строку без выбранной панели
- **THEN** колонка Deployment видна; в новой строке показано заблокированное поле «Сначала выберите график». Пустая таблица сохраняет согласованные заголовки и ширину сообщения о пустом списке.

#### Scenario: PH-REP-010-S02 Deployment не применяется к графику

- **GIVEN** метаданные подтверждают, что выбранная панель не поддерживает выбор deployment в действующем режиме
- **WHEN** строка отображается
- **THEN** поле видно, заблокировано и объясняет неприменимость. Наличие переменной в dashboard само по себе не включает фильтрацию для общей панели; обычная строка сохраняется без deployment.

#### Scenario: PH-REP-010-S03 Одиночный выбор для подходящего графика

- **GIVEN** подходящая панель имеет доступный каталог конкретных deployment
- **WHEN** пользователь открывает строку и выбирает deployment
- **THEN** список доступен и разрешает выбрать ровно одно значение; All, множественный выбор и свободный ввод не предлагаются. Без явного выбора новый deployment не назначается; обязательность сохраняется по PH-REP-008.

#### Scenario: PH-REP-010-S04 Применимость неизвестна или каталог недоступен

- **GIVEN** корректных метаданных текущего контекста нет либо варианты невозможно получить
- **WHEN** отображается строка
- **THEN** поле видно и заблокировано; показано, что метаданные или каталог недоступны и требуется проверка подключения Grafana. Это состояние не объявляется отсутствием переменной; сохранённое значение остаётся видимым и не очищается. Открытие редактора не запускает запрос Grafana.

#### Scenario: PH-REP-010-S05 Пустой список и сохранённое историческое значение

- **GIVEN** для подходящей панели каталог успешно не содержит актуальных вариантов, а в строке может быть сохранено историческое значение
- **WHEN** открывается строка без доступных альтернатив
- **THEN** поле остаётся видимым и заблокированным, причина отличается от ошибки загрузки; имеющееся значение обозначено сохранённым и не заменяется. Правила сохранения исторического значения PH-REP-008-S03 остаются прежними.

#### Scenario: PH-REP-010-S06 Устаревший доступный каталог

- **GIVEN** имеется последний корректный каталог подходящей панели и доступные варианты
- **WHEN** каталог помечен устаревшим
- **THEN** поле остаётся доступным для одиночного выбора с явным предупреждением; текущий выбор не заменяется первым значением или All.

#### Scenario: PH-REP-010-S07 Явная смена панели

- **GIVEN** в строке выбран deployment подходящей панели
- **WHEN** пользователь меняет панель на неподходящую либо другую подходящую
- **THEN** прежний deployment очищается по действующему правилу смены панели; поле остаётся в той же колонке и получает соответствующее доступное или заблокированное состояние. Для новой подходящей панели требуется новый явный выбор.

#### Scenario: PH-REP-010-S08 Перестановка и повторное открытие

- **GIVEN** шаблон содержит обычные строки и несколько строк DropApp с независимыми deployment
- **WHEN** пользователь меняет порядок, сохраняет и повторно открывает шаблон
- **THEN** порядок и значения сохранены, в том числе значения заблокированных полей; перемещение либо перерисовка не теряет deployment из модели строки. Обычные строки не получают дополнительный обязательный параметр.
