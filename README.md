# Летописец

Летописец — внутренняя веб-утилита для сопровождения нагрузочного тестирования.
Она собирает в одном интерфейсе данные из VictoriaMetrics, Grafana, DropApp и
Confluence, помогает находить проведённые тесты, фиксировать конфигурацию
стенда, проверять результаты на соответствие требованиям и формировать страницы
отчётов.

Основная идея утилиты — убрать ручную рутину вокруг нагрузочных тестов: поиск
временных интервалов, подготовку графиков, копирование конфигураций, проверку
порогов и сборку Confluence-страниц. Пользователь работает с тестом как с
готовой сущностью: видит период, тип, релиз, конфигурацию, статус требований и
может сразу перейти к деталям или сформировать отчёт.

## Для чего используется

Летописец полезен командам, которые регулярно проводят нагрузочные тесты и
готовят по ним отчётность. Утилита помогает:

- быстро найти нагрузочные тесты за выбранный период;
- сохранить и посмотреть конфигурацию DropApp на момент теста;
- открыть графики Grafana за точные границы теста;
- проверить тесты на соответствие нефункциональным требованиям;
- сформировать отчёты в Confluence по готовым шаблонам;
- выгрузить выбранные графики на существующую страницу Confluence;
- централизованно хранить настройки подключений и шаблоны отчётов.

## Основные сценарии работы

### 1. Просмотр и анализ нагрузочных тестов

Раздел "Тесты и отчёты" показывает список найденных нагрузочных тестов. Для
каждого теста отображаются релиз, тип, длительность, время начала и окончания,
статус проверки требований и наличие сохранённой конфигурации.

Пользователь может:

- запросить данные за последние 30 дней;
- отфильтровать тесты по релизу, типу, длительности, периоду, требованиям и
  наличию конфигурации;
- открыть детальную карточку теста;
- добавить комментарий к тесту;
- уточнить или изменить тип теста;
- запросить конфигурацию DropApp для конкретного теста;
- посмотреть графики Grafana по интервалу теста;
- выбрать один или несколько тестов для формирования отчётов.

### 2. Проверка нефункциональных требований

Для тестов можно настроить набор требований и проверять их автоматически.
Требования привязываются к данным из Grafana и VictoriaMetrics: для выбранных
панелей задаются PromQL-запросы и пороговые значения.

При проверке Летописец берёт фактические метрики за интервал теста, сравнивает
их с заданными порогами и сохраняет результат. В списке тестов видно, прошёл ли
тест проверку, а в деталях можно посмотреть измеренные значения и причину
статуса.

### 3. Формирование отчётов в Confluence

Утилита умеет создавать страницы Confluence по выбранным нагрузочным тестам. Для
этого используются настраиваемые шаблоны отчётов.

При генерации отчёта Летописец:

- определяет релиз и параметры теста;
- подставляет данные в шаблон страницы;
- добавляет сохранённую конфигурацию DropApp;
- рендерит выбранные панели Grafana в изображения;
- прикрепляет изображения к странице Confluence;
- вставляет графики в тело отчёта;
- возвращает ссылки на созданные страницы.

Есть также сценарий формирования общей страницы релиза: пользователь выбирает
родительскую страницу в Confluence, шаблон и набор тестов, после чего утилита
создаёт страницу релизного отчёта и связанные отчёты по тестам.

### 4. Работа с графиками Grafana

Раздел "Выгрузка графиков" позволяет получить графики по выбранному шаблону и
периоду без ручного перехода в Grafana.

Период можно задать несколькими способами:

- выбрать дату и время через календарь;
- ввести дату вручную;
- вставить Unix timestamp в секундах или миллисекундах;
- вставить ссылку на Grafana, из которой утилита извлечёт границы периода.

После отображения графиков их можно выгрузить на страницу Confluence по ID
страницы. Это удобно, когда нужно быстро дополнить уже существующий отчёт
актуальными графиками.

### 5. Сохранение конфигурации DropApp

Раздел "Конфигурация DropApp" нужен для фиксации состояния стенда. Пользователь
выбирает namespace и компоненты, после чего утилита получает текущую
конфигурацию из DropApp и сохраняет снапшот в базе.

В сохранённой конфигурации отображаются сервисы, поды, контейнеры, версии,
релиз, а также лимиты и запрошенные ресурсы по CPU/RAM. Снапшоты можно открывать
из истории, использовать в отчётах и выгружать архивом.

### 6. Настройка шаблонов отчётов

В разделе "Шаблоны отчётов" настраиваются шаблоны страниц Confluence. Для
каждого шаблона задаются:

- короткое имя;
- полное название;
- заголовок создаваемой страницы;
- тело страницы Confluence;
- список графиков, которые должны попасть в отчёт.

В теле шаблона можно использовать плейсхолдеры, которые утилита заменяет при
создании отчёта:

- `@release` — релиз;
- `@config` — блок с конфигурацией DropApp;
- `@graphics` — блок с графиками Grafana.

### 7. Централизованные настройки подключений

В разделе "Настройки" хранятся параметры интеграций:

- VictoriaMetrics: базовый URL, путь API, шаг агрегации, запрос поиска тестов;
- Grafana: базовый URL, путь рендера, API-ключ, размеры изображений, таймзона;
- DropApp: базовый URL, токен, список namespace;
- Confluence: базовый URL, путь API, токен, родительская страница отчётов;
- GigaChat: параметры API и OAuth для вспомогательного анализа данных.

Настройки можно менять через интерфейс, проверять подключение к сервисам,
выгружать в JSON и загружать обратно. Это упрощает перенос конфигурации между
стендами и восстановление настроек. При выгрузке настроек важно учитывать, что
файл может содержать токены и ключи доступа.

## Дополнительные удобства

- Главный экран `/main` даёт быстрый переход к основным разделам.
- При открытии корня приложения `/` пользователь автоматически попадает на
  `/main`.
- Логотип в левом меню всегда возвращает на главную страницу.
- В фоне выполняется регулярный поиск активных нагрузочных тестов.
- Если при фоновой обработке возникает ошибка, она отображается пользователю в
  интерфейсе.
- Список тестов можно быстро привести в рабочий вид фильтрами и сбросить фильтры
  одной кнопкой.
- Для отчётов можно выбирать несколько тестов и отслеживать статус генерации по
  каждому из них.
- Информация о тестах, конфигурациях, шаблонах, дашбордах и результатах проверок
  сохраняется локально в базе приложения.

## Как пользоваться

1. Открыть приложение и перейти на главную страницу `/main`.
2. В разделе "Настройки" заполнить параметры подключений к VictoriaMetrics,
   Grafana, DropApp, Confluence и при необходимости GigaChat.
3. В разделе "Графики и требования" подтянуть дашборды Grafana, выбрать нужные
   панели, указать PromQL-запросы и пороги.
4. В разделе "Шаблоны отчётов" настроить шаблоны Confluence и привязать к ним
   графики.
5. В разделе "Тесты и отчёты" запросить данные по тестам, проверить требования,
   выбрать нужные тесты и запустить генерацию отчётов.
6. При необходимости открыть раздел "Конфигурация DropApp", сохранить отдельный
   снапшот стенда или скачать его архивом.

## Что получает команда

Летописец делает подготовку отчётов по нагрузочному тестированию более
повторяемой и прозрачной. Вместо ручного сбора данных из нескольких систем
команда получает единый интерфейс, где можно увидеть тест, его метрики,
конфигурацию стенда, статус требований и готовые ссылки на страницы Confluence.

Это снижает риск ошибок при переносе данных, ускоряет оформление результатов и
помогает хранить историю тестов в одном месте.

## Техническая справка

Приложение реализовано как Spring Boot веб-приложение с Thymeleaf-интерфейсом.
По умолчанию запускается на порту `6500`.

Локальная база данных хранится в `./config/chronicler-db` и использует H2 в
режиме совместимости с PostgreSQL. Внешние настройки базы подключаются из
`config/application.properties`.

Для запуска из исходного кода:

```bash
mvn spring-boot:run
```

После запуска приложение доступно по адресу:

```text
http://localhost:6500/main
```
